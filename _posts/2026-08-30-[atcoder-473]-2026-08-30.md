## [E](https://atcoder.jp/contests/abc473/tasks/abc473_e)
10분 정도 관찰했을때 A_i 오른쪽으로 부터 누적된 값 중에 k - A[i]의 index를 j라고 하면
(i,j) 쌍으로 나타낼 수 있고, 이는 시작시간과 끝나는 시간, 즉 회의실 배정(데드라인 스케쥴)문제로 치환 가능하다는 것을 깨달았다. 
그래서 나머지 50분 동안 A_i 오른쪽으로 부터 누적된 값을 어떻게 빠르게 찾을 수 있을까 생각했다.
누적합은 단조 증가하기 때문에 lower_bound 성질을 이용해야 하나 싶었지만, MOD K의 세계에서는 누적합이 단조증가하지 않았다. 
그렇다고 MOD K를 사용하지 않으면 K를 더하면서 iterate해야 하는데 이부분에서 시간이 많이 걸렸다. 

그래서 이탐은 아니라고 생각해보고 counting 접근을 시작했다.  
종료 8분전에 한가지 아이디어가 떠올랏다.
A[i] A[i]+A[i+1] A[i]+A[i+1]+A[i+2] ... 이런식으로 생각하지말고 
S[i] S[i+1] .... 라고 생각해보자
그러면 내가 필요한 값은 k - A[i] + S[i] 이고 이게 있는 index를 빨리 찾아주면 된다고 생각했다.
그래서 n to 1 까지 역순으로 iterate하면서 vector에다 push해줬다.

근본 idea가 어려운건 아닌거같은데 좀 많이 해맸다.

## WA 
k < 1e9 인데 k만큼 vector<vector>만들었다 터졌다. map<vector>으로 바꾸니까 해결됨

```cpp
ll n,k;
vi a,d;
void solve() {
    cin>>n>>k;
    a.resize(n+1);
    d.resize(n+1);
    for(int i=1;i<=n;i++){
        cin>>a[i];
        a[i] %= k;
        d[i] = a[i] + d[i-1];
    }
    map<int,vi> as;
    for(int i=n; i >= 1; i--){
        as[d[i]%k].emplace_back(i);
    }

    ll mx = d[n];
    vector<pi> deadline;
    for(int i=1;i<=n;i++){
        auto x = a[i];
        ll need = k - a[i];
        need += d[i];
        need %= k;
        if(as[need].size()){
            deadline.emplace_back(as[need].back(),i);
        }
        if(as[d[i]%k].size()) as[d[i]%k].pop_back();
    }

    sort(all(deadline));
    int cur = 0;
    int cnt = 0;
    for(auto [end,start] : deadline){
        // cout<<start<<" "<<end<<endl;
        if(cur < start){
            cur = end;
            cnt++;
        }
    }
    cout<<cnt<<endl;
}
```
