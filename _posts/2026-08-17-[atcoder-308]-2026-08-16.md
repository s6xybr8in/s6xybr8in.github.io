# 총평 및 배운점
    E의 발상의 전환방법 suffix 두개를 prefix suffix로 해결
    그리디 체계화의 필요성을 느꼈다.

## [C](https://atcoder.jp/contests/abc308/tasks/abc308_c)
  $A_i/(A_i+B_i) < A_j/(A_j+B_j)$ 순서대로 sort하는 문제인데 한번 식정리 해줘야함  
  $A_i \times (A_j+B_j) < A_j \times (A_i + B_i)$
  $A_iB_j < A_jB_i$  로 식정리 가능하다. 
## [D](https://atcoder.jp/contests/abc308/tasks/abc308_d)
기본 그래프 탐색
## [E](https://atcoder.jp/contests/abc308/tasks/abc308_e)
  M을 iterate 하고 suffix 2개로 하면 E,X가 겹쳐서 못풀었는데 
  E를 iterate 하면 prefix,suffix 로 나눌수있어서 독립되게 볼수있다.
  이는 O(9n)으로 가능하다.
  ```cpp
  void solve() {
      cin>>n; a.resize(n);
      for(auto &i : a) cin>>i;
      cin>>s;
      vector pref(n,vi(3));
      vector suf(n,vi(3));
      for(int i=0;i<n;i++){
          if(i>0) pref[i] = pref[i-1];
          if(s[i] == 'M'){
              pref[i][a[i]]++;
          }
      }
      for(int i=n-1;i>=0;i--){
          if(i<n-1) suf[i] = suf[i+1];
          if(s[i] == 'X'){
              suf[i][a[i]]++;
          }
      }
      ll ret = 0;
      for(int i=0;i<n;i++){
          if(s[i] != 'E') continue;
          for(int j=0;j<3;j++){
              for(int k=0;k<3;k++){
                  ret += pref[i][j] * suf[i][k] * get_mex(a[i],j,k);
              }
          }
      }
      cout<<ret<<endl;
  }
  ```
## [F](https://atcoder.jp/contests/abc308/tasks/abc308_f)
### 접근 방식 (핵심 알고리즘)
  웰노운 그리디 우선순위 큐
  
### 시간/공간 복잡도 분석
  $O(n + mlogm)$
  ### WA(맞왜틀) 원인 및 디버깅 기록
  1. a를 내림차순으로 iterate하고, 할인이 제일 큰 쿠폰을 적용하자이다.
     정당성은 아무리 최솟값이 크다고 하더라도 지금 iterate한 값이 최대값이므로 항상 최선으로 제일 큰 쿠폰을 가져갈 수 있다.
     하지만 반례는 최솟값이 작은데 할인을 클수도있기 때문에 비싼 물건으로 적당히 할인받고 싼물건을 많이 할인받을 수 있다.
  2. a를 내림차순으로 iterate하고, 최솟값이 제일 큰 쿠폰을 매칭해준다.
    정당성은 현재 값이 최대값이므로, 최솟값이 제일 크면서 할인도 제일 큰 쿠폰을 매칭한다.
    하지만 반례는 최솟값이 작으면서 할인이 제일 큰 쿠폰을 적용할 수 있다는 것이다.
  3. a를 오름차순으로 iterate하고, 현재 it값보다 작은 최솟값들을 최대힙에 할인값을 넣고, 그 중 할인이 제일 큰 값을 뽑는다.
    정당성은 귀류법으로 증명이 쉽게 가능하다.

### 정답 코드
  ```cpp
  void solve() {
      cin>>n>>m; vi a(n),l(m),d(m);
      priority_queue<ll> Q;
      for(auto &i : a) cin>>i;
      for(auto &i : l) cin>>i;
      for(auto &i : d) cin>>i;
      sort(all(a));
      vector<pi> b(m);
      for(int i=0;i<m;i++) b[i] = {l[i],d[i]};
      sort(all(b));
      int i = 0;
      ll ret = 0;
      for(auto x : a){
          while(i < m and b[i].first <= x) Q.emplace(b[i++].second);
          if(Q.size()){
              x -= Q.top(); Q.pop();
          }
          ret += x;
      }
      cout<<ret<<endl;
  }
  ```
