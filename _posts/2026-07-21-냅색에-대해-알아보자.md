### [배낭채우기1](https://jungol.co.kr/problem/1077?cursor=IjgiLDksNg==)
동전 문제랑 똑같다. 
W가 유한하니 WlogN으로 나눠서 푸는 풀이도 된다.
```cpp
void solve() {
    cin>>n>>w; vector<pi> a(n);
    for(auto &i : a) cin>>i.first>>i.second;
    sort(all(a));

    for(auto [x,y] : a){
        for(int j=x;j<=w;j++){
            d[j] = max({d[j],d[j-x] + y,d[j-1]});
        }
    }
    
    cout<<d[w]<<endl;
}
```
