## [C](https://atcoder.jp/contests/abc471/tasks/abc471_c) 23:36
  규칙이 자기자신한테 있어서 그걸 나는 stack,queue로 구현했다. 
  근데 유비처럼 투포인터로 풀수도 있다.
  ```cpp
  void solve() {
      int n; cin>>n; vi a(n); for(auto &i : a) cin>>i;
      sort(all(a));
      stack<int> left;
      queue<int> right;
      for(auto i : a){
          if(i < 0) left.emplace(i);
          else right.emplace(i);
      }
      ll ret = 0;
      int cur = 0;
      while(n--){
          if(left.size() && right.size()){
              auto le = left.top();
              auto ri = right.front();
              if(abs(le-cur) <= abs(cur-ri)){
                  left.pop();
                  ret += abs(le-cur);
                  cur = le;
              }else{
                  right.pop();
                  ret += abs(ri-cur);
                  cur = ri;
              }
          }else if(left.size()){
               auto le = left.top();
               left.pop();
               ret += abs(le-cur);
               cur = le;
          }else{
              auto ri = right.front();
              right.pop();
              ret += abs(ri-cur);
              cur = ri;
          }
      }
      cout<<ret<<endl;
  
  }}
  ```
## [D](https://atcoder.jp/contests/abc471/tasks/abc471_d) 38:05
  쿼리 2를 보면 $(t_q-t_i) + val_i$ 의 최댓값을 빼주는 것과 같다.
  이때 $t_q$는 고정이므로 PQ에 $val_i - t_i$를 넣어주면 된다.
  ```cpp
  void solve() {
      int n,m; cin>>n>>m;
      priority_queue<int> Q;
      while(n--){
          int u,v,w; cin>>u;
          if(u==1){
              cin>>v>>w;
              Q.emplace(w-v);
          }else{
              cin>>v; 
              if(Q.empty()){
                  cout<<-1<<endl;
                  continue;
              }
              auto x = Q.top(); Q.pop();
              cout<<min(x+v,m)<<endl;
          }
      }
  }
  ```
## [E](https://atcoder.jp/contests/abc471/tasks/abc471_e) Upsolving
  $K\sum A_i^2 + L\sum A_i*A_j$ 이 공식은 10분만에 알아냈는데, 남은 50분동안 K계수만 알아내고 L계수를 못알아내서 못 풀었다.
  근데 이는 쉽게 풀 수 있다. 결국 $\binom{N}{K}$ 연산을 하는데 그중에서 $A[i]$ 하나만 뽑으면 $\binom{N-1}{K-1}$개 이다.
  마찬 가지로 $A_iA_j$는 2개를 먼저 뽑았다고 생각하면 되니까 $\binom{N-2}{K-2}$가 개수이다.
  $\sum A_iA_j$는 $\sum_{i=1}^{N-1} A_i * (D[n]-D[i])$로 $O(n)$에 구할 수 있다.
  ```cpp
  void solve() {
      using mint = modint998244353; // mod 998244353
      int n,k; cin>>n>>k; vi a(n);
      for(auto &i : a) cin>>i;
      vector<mint> d(n+1),f(n+1);
      f[0] = 1;
      for(int i=1;i<=n;i++) f[i] = i * f[i-1];
  
      mint ret = 0;
      for(int i=0;i<n;i++){
          d[i+1] = (d[i] + a[i]);
          ret += a[i]*a[i];
      }
  
      if(k==1){
          cout<<ret.val()<<endl;
          return;
      }
      mint ttmp = f[n-1];
      ttmp *= (f[k-1]*f[n-k]).inv();
      mint tttmp = f[n-2];
      tttmp *= (f[k-2]*f[n-k]).inv();
  
      ret *= ttmp;
      for(int i=1;i<n;i++){
          mint tmp = 2*tttmp;
          tmp *= a[i-1] * (d[n] - d[i]);
          ret += tmp;
      }
      cout<<ret.val()<<endl;
  }
  ```
